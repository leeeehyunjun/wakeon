**한 일**
- Java·Android SDK·adb·에뮬레이터 상태를 확인하고 화면·창 크기를 쟀다.
- Pleos 문서와 Maven 저장소의 SDK 원본 소스를 읽고 `docs/PLEOS_NOTES.md`에 초기화·브레이크·방향지시등·경유지 추가 방법을 코드 조각·출처와 함께 정리했다.

**확인 결과**
- 에뮬레이터 `Pleos_Connect_v2.1.0` 켜짐. Android 14(API 34), 2560×1440, 1dp = 1px.
- 창 크기: 가로 창 1682×1210(CLAUDE.md와 같음). 세로 창은 시스템 기록상 853×1300이라 단계 1에서 다시 재기로 함.
- 에뮬레이터의 Pleos 서비스 버전은 SDK 요구 최소 버전보다 모두 높음.
- Pleos Vehicle SDK로는 속도·기어를 읽을 수 없음(기어는 숨김, "구글 GEAR_SELECTION을 쓰라"). 속도·기어는 안드로이드 차량 기본 기능으로, 브레이크·방향지시등은 Pleos SDK로.
- 에뮬레이터에 내비 앱이 실제로 있음. TTS 엔진(Pleos)·음성 인식기도 들어 있음.
- 문서 주소가 `/en/docs/pleos-only/...`로 옮겨졌고 API 세부 페이지는 받아지지 않아 SDK 원본 소스로 함수 이름을 확인했다.

**막힌 것 / 사람이 할 일**
- adb가 PATH에 없음 → `~/.zshrc` 추가 명령 안내(이현준: 건너뜀).

## 단계 3 · 차량 신호와 시연 모드 — 2026-11-13 · 커밋 `06be059`

**한 일**
- 실제 차량 신호 연결: 기어·속도는 안드로이드 차량 기능 + Pleos 기어 값, 브레이크·방향지시등은 Pleos SDK. 시연 신호(DEMO_SCENARIO 3장 항목 전부)가 들어온 항목은 시연 값 우선.

**확인 결과**
