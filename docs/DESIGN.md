# Wakeon 디자인 기준 (개발용)

**화면 모양의 기준은 피그마 Design 페이지다.** 이현준(PM)이 와이어프레임을 바탕으로 직접 디자인한 시안이다. 레이아웃·색·글자 스타일·컴포넌트·아이콘·간격은 시안과 똑같이 만든다. 와이어프레임 페이지는 동작과 문구 확인용이다.

## 1. 피그마 연결 (필수)

- 파일: https://www.figma.com/design/4NOELduoRakuYTDFE6iyEe · file key `4NOELduoRakuYTDFE6iyEe`
- Design 페이지 node `47:3447`
- 저장소 루트 `.mcp.json`에 Figma MCP 서버(`{"mcpServers":{"figma":{"type":"http","url":"https://mcp.figma.com/mcp"}}}`)를 등록한다. 없으면 만들고, VS Code 재시작 → 서버 사용 허용 → `/mcp`에서 figma 로그인(이현준이 브라우저에서 승인)을 안내한다.
- 화면을 만들 때마다: ① 아래 3장 표의 **앱 창 node**로 `get_design_context`(레이아웃·값)와 `get_screenshot`(모양) ② 만든 뒤 에뮬레이터 캡처와 시안을 나란히 비교 ③ 다른 점을 고친다.
- Figma 연결이 안 되면 멈추고 이현준에게 보고한다(이 문서의 값만으로 대충 만들지 않는다).

## 4. 문구 규칙

시안의 문구를 기본으로 쓴다. 단, 아래는 고쳐서 쓴다.

1. **소리 내어 말하는 문장**(큰 질문·안내 문장)은 `SPEC.md` 7-2 대사(V-ID)와 같아야 한다. 시안과 다르면 대사 문장을 쓴다. 예: W-08 시안 "가까운 쉼터로 안내할까요" → V-20 "가까운 쉼터로 안내할게요".
2. 따옴표·띄어쓰기·오타는 고친다: `“그만" 라고` → `“그만”이라고`, `15분뒤` → `15분 뒤`, `쉬는걸` → `쉬는 걸`, `삳태` → `상태`, `준비 됐어요` → `준비됐어요`, `12Km` → `12km`.
3. 시안 문구가 2026-11-12 기획 변경(차량 제어 없음) 전 문구인 곳은 SPEC을 따른다.
   - W-13: "15분 중 · 등받이를 젖히고 눈을 붙이세요" + 칩 "알람 천천히 커짐 · 1분 전 미리 알림 · 창문 조금 열기"
   - W-13b: "등받이를 세워 주세요" + 칩 "알람 3단계까지"(종 아이콘)
   - E-3: "등받이는 브레이크를 밟는 순간 먼저 세워요" → 차량 제어가 없으니 "등받이를 세워 주세요"
4. 쉼터 이름·거리는 하드코딩하지 않고 `assets/demo_route.json`에서 읽는다.
5. 고친 곳은 `docs/DESIGN_DIFF.md`에 표로 남긴다(화면, 시안 문구, 앱 문구, 이유). 디자이너가 시안을 맞출 때 쓴다.
