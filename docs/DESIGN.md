## 2. 창과 배치

| 창 | 공식 규격(dp) | 에뮬레이터 v2.1.0 실측(dp) | 쓰는 화면 |
| --- | --- | --- | --- |
| 세로 창 (1:1) | 840 × 1184 | 841 × 1210 | 주행 화면 전부(W-04~W-11, E-1~E-3), 시연 영상의 모든 장면 |
| 가로 창 (2:0) | 1700 × 1184 | 1682 × 1210 | 정차 화면(W-01~W-03b, W-12~W-18)의 기본. 1차 제출은 세로 레이아웃으로 대신해도 된다 |

- 창 크기는 기기가 정한다. Compose에서 `BoxWithConstraints`로 받은 폭이 1200dp 이상이면 가로 레이아웃, 아니면 세로 레이아웃.
- 창 안 여백: 가로 창 64dp, 세로 창 57dp.
- 창 바깥(Driving view, 상태바, GNB, 창 손잡이)은 시스템 영역이다. 앱이 그리지 않는다. 앱이 직접 시각·상태바를 그리지 않는다.

## 4. 글자 (17″ 기준, dp = px)

| 역할 | 크기 | 굵기 | 예 |
| --- | --- | --- | --- |
| 큰 숫자 | 77 | Bold | "12km", 휴식 타이머는 293 Light |
| 핵심 문구 | 61~77 | Bold | 질문 문장, "졸음 신호가 보여요" |
| 선택지 | 64 | Bold | "“응”", "“아니”" |
| 버튼·부제 | 45 | Bold | "경유지로 넣을까요?", "+ 5분" |
| 안내 문장 | 40 | Regular | "가까운 쉼터로 안내할게요" |
| 일반 | 33 | Regular | "“그만”이라고 하면 멈춰요" |
| 칩·라벨 | 32 | SemiBold | "대화 3 / 6", "듣는 중" |

- 글꼴: 시안은 Pretendard. 앱에는 Pretendard(OFL 라이선스)를 `res/font`에 넣는다. 받기 어렵으면 시스템 기본 글꼴로 먼저 진행하고 보고한다.
- 최소 크기 규칙: 핵심 61dp, 일반 33dp, 터치 139dp(주행 중). 응/아니 버튼은 최소 387×200dp.

## 5. 공통 요소

- **헤더**: 왼쪽 "W" 로고 원 + "Wakeon", 오른쪽에 상태 칩(대기 중 / 대화 3 / 6 / 잠시 멈춤 / 확인 / 경고 / 쉼터 안내 / ✓ 추가됨 / 곧 도착 / 기어 P · 속도 0 / 휴식 중 / 알람 2단계 …).
- **음성 상태 오브**: 말하는 중(그라데이션, 천천히 숨 쉬듯), 듣는 중(accent 링 + "듣는 중"), 멈춤(회색).
- **하단 안내 한 줄**: 다음에 할 수 있는 말("“그만”이라고 하면 멈춰요"). 33dp, textTertiary.
- 주행 중 화면은 요소 3덩어리 이하. 애니메이션은 0.3초 이하 페이드만.
